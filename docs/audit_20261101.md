# Audit record: the 1 November 2026 revision package

This file records how the revision was checked, what the checks found, and what remains open.
It contains no manuscript text, no correspondence and no individual-level data: it is a record
of *process*, written so that the checks can be repeated or challenged. Where a finding concerns
a specific place in the manuscript, the place is named by section or table number only.

The audit was run by the authors on their own revision. It is not an independent review, and
nothing here should be read as a claim that the manuscript is free of error — only that the
checks below were carried out and that the failures they produced were fixed.

---

## 1. What was compared

| object | what it is | used for |
|---|---|---|
| submitted manuscript | the file as first submitted | reference text for the version-to-version comparison |
| revised clean copy | the version to be re-submitted | the text every other copy must reproduce |
| tracked copy | the same revision as recorded changes | checked by accepting every revision |
| redline copy | the same revision as inline formatting, no revision records | checked by removing every struck run |
| supplementary file | tables S1–S48 and figures S1–S2 | cross-checked against every value the text quotes |
| response documents | point-by-point replies | checked for statements that the manuscript does not support |
| archive | this repository, and the Zenodo record it is cited as | checked for reachability and for the scripts behind every number added at revision |

## 2. Method

1. **Full-text extraction.** Every paragraph and table cell of each `.docx` was read
   programmatically, in document order, preserving table structure.
2. **Paragraph alignment.** The submitted and revised texts were aligned at paragraph level; each
   rewritten paragraph was then compared token by token, so that a changed number could not hide
   inside a rewritten sentence.
3. **Arithmetic re-derivation.** Every derived quantity was recomputed from the tables it is
   supposed to come from — increments, differences between models, differences between outcome
   conventions, net benefit at each threshold, referral fractions, and the counts that should sum
   to the analysis sample.
4. **Figure inspection.** Each figure was rendered and read back against the table it summarises.
5. **Copy invariants.** The three marked copies were reduced to plain text by the two independent
   routes above and compared character by character with the clean copy.
6. **Archive check.** The public repository was queried, anonymously, for the scripts behind every
   analysis added at revision, and the citation record was queried for its version and date.
7. **Statement check.** Each claim in the response documents was matched against the sentence or
   table in the manuscript that is supposed to carry it.

**What this audit cannot see.** It cannot see the individual-level records, so it cannot
re-derive any estimate from source data; it checks that reported numbers are internally
consistent and that each is traceable to a committed aggregate table, not that they are correct.
It also cannot see how the files render in the publisher's PDF pipeline.

## 5. Open items

These are stated in the manuscript as limitations or are carried here as known gaps. None is a
defect that a further edit could close.

1. **Design-based intervals for the exported models.** Coefficients, the increment and the three
   benchmark models now carry design-based intervals; the exported models still carry record-level
   bootstraps, because the archived run that produced them is not reproducible from this
   repository. Both are reported, and the table says which is which.
2. **Two interval families.** Record-level and design-based intervals differ by resampling unit.
   Both are given side by side rather than one being substituted for the other; the design-based
   interval is the reproducible one and is the one to quote if only one is quoted.
3. **Linkage ambiguity.** The two hospital systems share no patient identifier, so laboratory
   panels were linked on name and sex. The number of ambiguous matches was not quantified; the
   manuscript states the consequence rather than a count.
4. **Date of the original protocol decisions.** Three groups of decisions are dated. Two are
   anchored to commits; the first is not, and no external record of it exists.
5. **Archive version.** The Zenodo record is v1.0.0 (12 October 2026) and predates the revision.
   A later version is needed before the archive and this repository agree.
